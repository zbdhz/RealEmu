## 误码模型的边界

`phy_error_model_off=0` 为默认兼容模式：使用已有整包 PRR 表，并对超过干扰门限的重叠接收施加失败判定。其改进是完整的信号持续时间语义；它不是 ns-3 NistErrorRateModel 的等价实现。

`phy_error_model_off=1` 为分段模式：每段计算期望信号与干扰加噪声的 SINR，查表得到 **单 bit 成功率**，按段内 bit 数计算幂并累积。起止变化在独立周期轴处理，误码计算通过 FIFO 与整数乘法状态机完成。这个模式不会再用“存在重叠”直接否决接收。功率采用固定点近似；单bit成功率及概率乘积为16bit，接近100%成功率时存在量化精度限制，不能保证任意目标PER都可由现有表精确表达。噪声底暂保留旧实验的 1mW，不能直接理解为真实 Wi-Fi 热噪声配置。严格数值验收还需检查这些精度和模型假设，不能只换一份表就认定等价。

**现有 `mem/Per.mem` 是整包 PRR 表，不能直接作为 mode 1 的标定表。** mode 1 的测试使用人工设定的单 bit 概率或0/FFFF确定性端点，验证时长加权、分段累积和模式差异。严格对齐 ns-3 仍需要恢复参考配置并导出相应的误码表/模型；本轮不以仿真 PASS 宣称吞吐数值已对齐。

## 寄存器与计数语义

偏移均相对于节点 MAC 基址；PHY 偏移已经包含 `0x200`。

| 偏移 | 含义 |
|---|---|
| MAC `0x050/054/058/05C` | 配置代次、cycles/us=250、当前CW指数、NAV剩余us |
| MAC `0x060/064/068` | 控制帧MCS、退避seed、诊断ABI版本 |
| MAC `0x06C` | 写1：锁存计数；写2：清零实时计数，不改已锁存快照 |
| MAC `0x070/074/078/07C` | 快照序号、响应阶段、交换编号、显式NAV复位 |
| MAC `0x080..0x0AC` | 依次为输入进入内部发送队列、DATA尝试、RTS尝试、成功交换、CTS等待失败、ACK等待失败、最终重试丢弃、发送完成、向上递交DATA、忽略响应、输入丢弃、PHY CRC失败 |
| PHY `0x214/218/21C` | 诊断版本、快照/清零命令、快照序号 |
| PHY `0x220..0x240` | 依次为处理信号事件、启动接收、CRC成功、CRC失败、有重叠的接收帧、发射帧、重复信号事件、非法信号事件、CRC正确但交付FIFO已满的丢弃 |
| PHY `0x260/264/268/26C` | 能量门限、同步门限、干扰有效门限、误码模式；门限为有符号1/32dB |

MAC的DATA/RTS尝试在提交到PHY发送队列时计数；PHY的发射计数在实际TXSTART时增加，二者观察边界不同。seed配置值变化会重置随机序列，同值重写不会回卷序列。

计数器32bit、模2^32回绕。每个快照为同一时钟边界的计数，不逐寄存器重新采样；先后读取快照序号可以检测其他软件读者是否换了快照。清零与事件同周期时清零优先。快照序号不随计数清零复位。MAC与PHY快照各自独立，不声称跨模块或跨节点同时锁存。

MAC输入队列采用背压，不能把未被接口接受的请求计为“硬件丢包”；成功与最终重试丢弃都会计入完成。上交DATA按接收帧计数，包含重传副本；主机唯一包去重仍属于驱动/测试统计边界。PHY向MAC交付的FIFO满时继续推进物理时间，并在 `0x240` 明确记录未能交付的正确帧；CRC成功计数仍增加。PHY的“重叠帧”按一次解码接收计1，与进入系统的干扰事件个数不同。

兼容字段 `sigTime/ofdmSymbolTime` 对应本轮固定20us/4us legacy OFDM；旧 NAV 下限所使用的 `maxNum/phyDelayTime` 不再参与预约计算。这些兼容寄存器的读写不改变公共时长公式的固定20us前导/头部和4us符号长度。控制速率变化后，实验配置应同步核对 EIFS，不应假定所有旧兼容字段仍具有原先的副作用。

## 仍需后续验证

Bluesim 功能通过与 BSC 生成 Verilog 均不替代 Vivado 综合/布局布线的250MHz时序报告。活跃信号表、功率加法、概率乘法与FIFO会增加资源；需在板级实现中检查资源和关键路径。最终数值对照还需要匹配控制速率、CW、重试限制、误码表、负载、去重和统计窗口，执行多seed对比。
